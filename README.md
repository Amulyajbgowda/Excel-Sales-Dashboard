# 📊 Mobile Sales Dashboard using Microsoft Excel

## 📌 Project Overview

This project is an interactive Excel dashboard developed to analyze mobile sales data. It provides insights into sales performance, customer behavior, city-wise sales, and payment methods using Pivot Tables, Pivot Charts, Slicers, and Excel formulas.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

---

## 📈 Dashboard Features

- Total Sales
- Total Quantity Sold
- Brand-wise Sales
- City-wise Sales
- Payment Method Analysis
- Customer Ratings
- Interactive Slicers
- Dynamic Charts
